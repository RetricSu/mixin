# 密信

两台电脑，同一个密码，传一句秘密。

双击打开 → 选加密或解密 → 输入密码。密文是一行 `MX1.` 开头的乱码，微信 / 邮件发出去即可。对方用同一个程序、同一个密码还原。

给普通人用的成品在 `dist/`（桌面 `~/Desktop/密信/` 也有一份）：

| 系统 | 怎么打开 |
| --- | --- |
| Mac | 双击 `双击我.command`（打不开就右键 → 打开） |
| Windows | 双击 `密信.exe`（SmartScreen 拦了就「更多信息 → 仍要运行」） |

密码请当面说 / 打电话说，不要和乱码发在同一个聊天里。忘了密码谁都解不开。

和桌面上的 `encrypt.js` **不通用**（那个是本机随机密码；这个是双方自己输入）。

## 自己编译

```sh
./build.sh
```

会跑测试，并编出 Mac（Intel + Apple Silicon）和 Windows 的成品到 `dist/`。

Windows 交叉编译依赖本机的 `x86_64-w64-mingw32-gcc`（Homebrew `mingw-w64`）。

## 技术

- AES-256-GCM
- 密码经 sha256 变成 32 字节密钥，所以长度不限
- 密文：`MX1.` + base64(iv 12 字节 + 密文 + tag 16 字节)

这是个人小工具，不是银行级。弱密码 + 乱码丢在网上，有被撞出来的可能。二进制没签名。
